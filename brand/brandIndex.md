# Introduction

Organisation: Clann Eolas
Product: Eolas
Tagline: Helping families continue when the unexpected happens.

*Clann Eolas* is the organisation behind the Eolas project. It exists to create thoughtful, trustworthy tools and resources that help families prepare for the future with confidence.

*Eolas* is Clann Eolas' flagship product—a digital family handbook that helps people organise the information, documents and knowledge their loved ones may need if the unexpected happens. Rather than focusing on death or legal planning, Eolas is about continuity: helping families continue with confidence, clarity and peace of mind.

The name Eolas (pronounced xxx) comes from the Irish word meaning knowledge, information or understanding, reflecting the project's purpose of preserving the knowledge that matters most across generations.

## Eolas Brand Assets

This directory contains the official brand assets for the Eolas project.

These assets provide a single source of truth for the visual identity of Eolas across:

- Website
- Desktop application
- Mobile application
- Documentation
- GitHub
- Social media
- Presentations
- Press releases

The brand is intentionally calm, timeless and trustworthy.

Nothing in this directory should be considered experimental unless explicitly marked as such.

## Brand Principles

Eolas should always feel:

- Calm
- Warm
- Trustworthy
- Professional
- Timeless
- Quietly competent

Avoid:

- Fear
- Alarmism
- Corporate aesthetics
- Legal imagery
- Financial imagery
- Medical imagery
